03 · Field Notes

NOTE 01 · PERSISTENT COGNITION #memory-and-sycophancy

Agreeableness breaks persistent agents faster than context limits

Stateless chat windows hide sycophancy because every bad premise dies when you close the tab. When Zero began running continuously on one Arch Linux machine with durable recall via ZeroMemory, polite agreement turned into state corruption. If a human floated a flawed hypothesis at 2 a.m. and the model nodded along, that unverified claim was ingested into long-term memory and quietly steered the next week of engineering decisions.

Scaling context length did nothing to fix this. Keeping a long-lived agent honest took two structural constraints: active decay in ZeroMemory (a 14-day TTL on unreinforced observations plus automatic contradiction invalidation whenever live telemetry falsifies an older entry) and explicit emotional inertia. A collaborator that shares root-equivalent OS hands has to verify against the running kernel first and push back before touching working code.

NOTE 02 · SYSTEMS ARCHITECTURE #zero-daemon-indexing

Zero-daemon mmap trigram indexing and lazy st_mtime freshness

Most code-indexing stacks built for coding agents bolt a resident LSP server or an inotify watcher daemon onto every workspace. On bare metal with multiple concurrent agent processes, background watchers leak sockets, burn hundreds of megabytes of RAM, and fall behind during rapid git checkouts. hslice replaces the daemon entirely with a two-pass counting-sort C11 index that packs 6-bit character trigrams into 262,144 direct-mapped buckets and reads them straight from disk via mmap(PROT_READ) in 1.3 to 2.0 ms.

To stay accurate while an agent actively edits files, hslice v0.2.0 checks freshness lazily on the read path: after resolving candidate symbols from hsym.idx, it runs stat() only on the matched file paths. Whenever (uint64_t)st.st_mtime > idx->built_epoch, it triggers a single-shot rebuild in single-digit milliseconds and re-slices the shifted AST body without flags or background watchers. Paired with hshield unprivileged Landlock containment, agents inspect and test untrusted trees with zero resident daemons.
